# Customization Guide

## Colors

Edit the custom properties at the top of `assets/css/style.css`. The main brand tokens are `--navy-950`, `--orange`, `--green`, `--surface`, and `--muted`. Dark-theme overrides are in `assets/css/dark-mode.css`.

## Typography

The template uses the system `Inter`/UI sans-serif stack for fast loading. Change the `font-family` on `body` to use another local or hosted family.

## Content

Page copy is contained in each HTML file. Shared navigation, footer content, booking-modal content, theme handling, RTL handling, and form validation are in `assets/js/main.js`.

## Images

Replace `assets/images/driveway-hero.png` and `assets/images/driveway-hero.webp` with images of the same name to keep existing references. Use wide landscape images with the subject on the right and clear space on the left.

## Dashboard data

Demo student details are in `pages/dashboard.html`. Lesson-slot selection and report behavior are in `assets/js/dashboard.js`.
