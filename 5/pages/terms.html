Using this demonstration

Northstar Tutoring is presented as a static website template. All courses, fees, schedules, results, people and services are illustrative. Nothing shown here forms an enrolment agreement or a promise of educational outcomes.

Accounts and the student portal

Sign-in and registration are demonstration interactions. The dashboard is openly accessible and contains fictional student records. No access control is provided; do not put real student records into these files.

Learning materials

The downloadable practice sheets are sample materials for evaluating the template. A tutor should review and adapt any learning materials before classroom use.

Prices and enrolment

Displayed prices are demo values used to demonstrate the fee calculator. A live operator must confirm applicable fees, payment terms, refunds, batch availability and enrolment conditions.

Respectful use

A production centre should set clear expectations for respectful participation, appropriate communication and responsible use of learning materials.

Template and resource licences

The original HTML, CSS and JavaScript are supplied for use and customisation. Third-party fonts and icons retain their original licence terms. See the documentation folder for credits and licences.
